# StudyFlow logo

## Selected logo: Page flow

The selected option is **1 — Page flow**, an open book with a rising right
page. Use `studyflow-icon-book.svg` or its matching 1024 × 1024 transparent
PNG. Use `studyflow-icon-book-white.svg` / `.png` on dark backgrounds.
These final vector redraws use two solid shapes, no text, and a slightly
wider central gap to keep the pages distinct at sidebar size. The original
generated concept is preserved in `options/01-page-flow.png`.

Earlier concepts below are retained. The selected book symbol is now used in
the app sidebar, sign-in screens, landing-page header/footer, and favicon.

## Pictorial symbol (latest)

`studyflow-symbol-v2.svg` and `studyflow-symbol-v2.png` are the latest
text-free logo: an open book with a sweeping page. The SVG is a clean,
three-path vector drawing; the PNG is a matching 1024 × 1024 transparent
export. There are no initials or letterforms. `studyflow-symbol-concept.png`
preserves the original generated concept, before the vector redraw.
The earlier SF files below are retained as previous concepts.

## Previous SF concept

A geometric SF monogram with a folded page corner, paired with an outlined
Bahnschrift Semibold wordmark. Flat colors; no gradients, shadows, or raster
content inside the SVGs. All deliverable logos have transparent backgrounds.

| Use | SVG and PNG basename |
| --- | --- |
| Default symbol | `studyflow-mark` |
| White symbol for dark surfaces | `studyflow-mark-white` |
| One-color charcoal symbol | `studyflow-mark-ink` |
| Full logo on light surfaces | `studyflow-logo` |
| Full logo on dark surfaces | `studyflow-logo-dark` |
| One-color white full logo | `studyflow-logo-white` |

Symbol PNGs are 1024 × 1024. Full-logo PNGs are 2400 pixels wide.
SVGs scale to any size and contain outlines, not live font references.
`studyflow-brand-preview.png` is a light/dark proof sheet, not a transparent logo.

Colors: blue `#2563EB`, fold `#1E40AF`, charcoal `#182230`, white `#FFFFFF`.
The dark-background lockup uses brighter blue `#60A5FA` for contrast.

Use the symbol at a minimum 24 × 24 CSS pixels. Preserve its aspect ratio and
leave at least one stem-width of clear space. Do not add effects or stretch it.
Use the full logo at 140 CSS pixels wide or larger. On busy backgrounds,
use the one-color version against a plain, sufficiently contrasting surface.

Regenerate outlined variants: `python benchmarks/export_brand.py`.
Regenerate PNGs and verification proof: `node benchmarks/render_brand.mjs`.
The installed font is used locally for outlining; no font binary is included.

The selected Page flow symbol above is the website logo. These older exports
remain available as design history and are not used by the website.
