# Stage and performance-gate adaptive estimation

StudyFlow will keep Adaptive Estimate unavailable for the first five completed Academic Tasks, generate hidden transparent-correction predictions for tasks six through ten, and expose that correction only when its five chronological predictions have at least ten percent lower mean absolute error than Original Estimates. The correction uses the median actual-to-original duration ratio from the latest twenty applicable records, uses category-specific history once five completed tasks exist in that Category, and otherwise uses the student's overall history. The correction is not capped because repeated large estimation errors are legitimate behavior to learn. When a Category first produces an Adaptive Estimate above twice or below half the Original Estimate, StudyFlow explains the evidence and requires acknowledgment; subsequent predictions retain a visible explanation without repeatedly blocking the student unless the adjustment factor changes substantially. After thirty completed tasks, Ridge Regression will generate ten hidden chronological predictions using only Original Estimate, Category, Priority, recent overall estimation ratio, and recent Category-specific ratio; Course and Notes are excluded. Its earliest activation is after task forty, and it replaces the correction baseline only when those predictions have at least ten percent lower mean absolute error than both the baseline and Original Estimates. After activation, each method is re-evaluated after every completion over the latest ten eligible chronological predictions and falls back to the best qualifying method if it loses the ten-percent advantage. This avoids presenting unsupported personalization while allowing the system to adapt as evidence becomes sufficient.
