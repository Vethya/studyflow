# Use server-managed browser sessions

StudyFlow will serve the React application and FastAPI API from one HTTPS origin and authenticate browser requests with random opaque session identifiers stored in `Secure`, `HttpOnly`, `SameSite=Strict`, `__Host-` cookies. The backend will store revocable session records, protect state-changing requests against CSRF, rotate sessions after authentication-sensitive events, and never place authentication tokens in browser storage. Students may authenticate with a password or Google OpenID Connect; Google receives only `openid`, `email`, and `profile` scopes, and a matching password account requires password confirmation before linking. Password accounts remain unusable until a single-use, time-limited email-verification token confirms ownership, while Google identities require `email_verified=true`. Password recovery uses rate-limited, single-use, expiring email tokens and revokes existing sessions after a successful reset. JWT browser authentication was rejected because the approved scope has no native mobile client, public API, or third-party integration that would justify its additional token lifecycle and revocation complexity.
